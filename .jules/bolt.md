- N+1 query issue fixed in `InventoryController.UpdatePORequisitionDetail()`. Inside a `foreach` loop, `_inventoryDbContext.PurchaseRequestItems.Find()` and `_inventoryDbContext.SaveChanges()` were repeatedly called for cancelling items. The optimization utilized `Contains()` to batch fetch the items to be cancelled and shifted `SaveChanges()` to run exactly once after modifying the entities, dramatically reducing database roundtrips.
