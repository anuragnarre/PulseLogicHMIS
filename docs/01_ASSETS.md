## Patient File Uploads (`fileuploads/`)

> ⚠️ **SECURITY NOTE — PLHMR-SEC-012**
>
> This directory is currently inside `wwwroot` and is therefore **directly web-accessible without authentication**. Patient documents (lab reports, consent forms, radiology images) uploaded by staff are stored here.
>
> **Current mitigation:** `.gitignore` now excludes all files in this directory to prevent PHI from being committed to version control.
>
> **Required fix (deferred):** Move `fileuploads/` to a directory *outside* `wwwroot` and create an authenticated ASP.NET Core file-serving endpoint that validates the JWT/session before serving any file.

### Subdirectory Structure (runtime-generated)
```
fileuploads/
├── Employee/           ← Employee profile photos
├── LabReports/         ← Uploaded lab result files
├── RadiologyImages/    ← Radiology attachments
├── ConsentForms/       ← Patient consent PDFs
└── misc/               ← Other uploads
```

### Upload Security Policy (Post v2.0.1 Changes)
| Rule | Value |
|------|-------|
| Max file size | 50 MB per file |
| Allowed extensions | `.pdf .jpg .jpeg .png .gif .bmp .tiff .doc .docx .xls .xlsx .csv .txt .dcm .zip` |
| Path traversal | Blocked via `Path.GetFullPath()` comparison |
| Filename | Sanitised with `Path.GetFileName()` — strips any path components |
| Error response | Generic message only — full path/exception never returned to client |
