## Architecture Overview
The application uses an Angular 10+ frontend structured into feature modules, communicating with an ASP.NET Core Web API backend.
- **Frontend:** Angular components organize the UI, with services handling HTTP communication via API endpoints to the backend. Routing is modularized per feature.
- **Backend:** ASP.NET Core Controllers expose RESTful API endpoints. They delegate complex operations to the `Services` layer (BL), which orchestrates data access via Entity Framework Core (`DalLayer`) and Data Access Logic functions.
