### N+1 Query in UpdateReceivedQuantityInRequisitionItems (Resolved)
- **Anti-pattern:** Looping over `dispatchItems` to execute an individual query `db.RequisitionItems.Where(r => r.RequisitionId == d.RequisitionId && r.RequisitionItemId == d.RequisitionItemId).FirstOrDefault()` inside the loop for each item. Followed by individually marking entities as modified.
- **Optimization:** Replaced the N queries with a single query fetching all required `RequisitionItems` in one go. Collected keys (RequisitionId, RequisitionItemId), retrieved matching entities into a Dictionary in memory, and modified tracking states automatically via EF Core object reference changes instead of explicitly via `.State = EntityState.Modified`. Resulted in an 89.10% improvement based on manual benchmark measurements (from 16803 ms to 1832 ms).
